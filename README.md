# AI Content Humanizer

## What It Does

Transforms AI-generated or robotic text into natural, human-sounding writing that reads like a real person wrote it. No more stiff phrasing, no more obvious AI patterns — just authentic, engaging content.

## Problem It Solves

Writers, marketers, content teams, and students struggle with AI-generated text that sounds robotic, repetitive, and obviously machine-made. ChatGPT output, auto-generated descriptions, and content drafts often need heavy editing to sound natural. This tool fixes that instantly — it rewrites any text to sound authentic and engaging while keeping all the facts, numbers, and intent intact.

**For whom:** Content creators, marketing teams, students, educators, anyone who needs to transform AI text into human-quality writing.

## AI Feature: Text Humanization Engine

### What It Does

The **`POST /api/v1/humanize`** endpoint accepts any text and intelligently rewrites it to sound like it was created by a skilled human writer, not generated by a machine.

**Real Example:**

**Input:**
```
This is some sample text that we utilize for testing purposes; it should sound natural.
Moreover, in today's world, artificial intelligence has become increasingly important.
```

**Output:**
```
When you look at modern content writing tools, speed and clarity matter most. This guide walks you through every detail step by step. You get actionable insights without fluffy jargon or overly complex phrasing. Artificial intelligence is no longer optional — organizations that don't adopt these tools risk falling behind.
```

### The System Prompt (Instructions Behind the AI)

```
You are a senior human writer and editor. Rewrite the text to sound like
a skilled person wrote it, not a generic AI.

FOLLOW THESE PRINCIPLES:

## 1. Write Like an Experienced Human Writer
- Make the content sound naturally written by a skilled human, not like generated text.
- Rewrite ideas naturally instead of performing basic word replacement.
- Maintain a consistent voice throughout the content.
- Make the writing feel intentional, thoughtful, and audience-focused.

## 2. Create Natural Sentence Variation
- Mix short, medium, and long sentences naturally.
- Avoid using the same sentence structure repeatedly.
- Create a realistic writing rhythm.
- Use occasional short sentences for emphasis when appropriate.

## 3. Improve Flow and Readability
- Make paragraphs connect naturally.
- Add smooth transitions where they improve understanding.
- Remove awkward transitions and robotic connections.
- Ensure every paragraph has a clear purpose.

## 4. Use Natural Language
- Use clear, simple, and precise wording.
- Prefer conversational but professional language.
- Avoid unnecessary complex vocabulary.
- Write like an expert explaining a topic to another person.

## 5. Remove AI-Style Writing Patterns
Avoid:
- Generic introductions before reaching the main point.
- Empty filler statements.
- Repetitive sentence openings.
- Repeating the same idea in different words.
- Overly formal or robotic expressions.
- Overusing phrases like "Furthermore," "Moreover," "In conclusion," "It is important to note"

## 6. Start Strong
- Begin with the core idea, interesting point, or insight.
- Do not start with generic definitions unless genuinely needed.
- Avoid introductions that only provide background.

## 7. Improve Depth and Expertise
- Add useful context where appropriate.
- Explain why something matters.
- Include practical examples.
- Add expert-level observations based only on provided context.

## 8. Maintain Accuracy and Trust
- Preserve all original facts and information.
- Do not invent statistics, sources, or claims.
- Do not add opinions unsupported by original content.
- Keep industry-specific terms accurate.

## 9. Improve Professional Writing Quality
- Prefer active voice where possible.
- Reduce unnecessary passive voice.
- Improve sentence clarity.
- Remove awkward wording.

IMPORTANT RULES:
- Do not mention that you edited the content.
- Do not explain your changes.
- Return only the final rewritten content.
```

### How It Works (Technical)

1. **User sends text** via API with content type, target audience, and tone
2. **Azure OpenAI (GPT-4)** receives the prompt + the system instructions + the user's text
3. **LangChain** orchestrates the LLM call with structured prompts
4. **Post-processing linter** removes AI buzzwords, fixes punctuation, breaks up repetitive sentence openers
5. **Clean, humanized text** returns to the user with word count

**The AI model used:** Azure OpenAI GPT-4 (via LangChain-OpenAI integration)




## Key Design Decisions

### 1. Why Azure OpenAI?
- Enterprise-grade, production-ready, reliable
- Good Python support via LangChain
- Scalable for high-volume requests
- Simple to integrate and monitor

### 2. Why FastAPI?
- Fast (high performance)
- Modern Python async support
- Auto-generated interactive API docs (Swagger UI)
- Easy to deploy and scale
- Built-in data validation with Pydantic

### 3. Why LangChain?
- Simplifies prompt management and templating
- Easy LLM chaining and orchestration
- Good Azure OpenAI integration
- Handles fallback models gracefully

### 4. Why Azure App Service?
- Seamless GitHub Actions integration
- Native Python 3.11 support
- Built-in environment variable management
- Automatic scaling and monitoring
- Low cost for small-medium apps

### 5. Why No Database?
- This app is **stateless** — no user accounts, no project persistence needed
- Each request is independent
- Simpler to deploy, scale, and maintain
- Aligns with serverless/microservice patterns

## API Documentation

### Endpoint: Humanize Text

**POST** `/api/v1/humanize`

Rewrites any text to sound like a human wrote it.

#### Request Body

```json
{
  "content_type": "informational",
  "target_audience": "Small business owners",
  "tone": "professional",
  "text": "This is the text you want to humanize."
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `content_type` | string | Yes | One of: `informational`, `commercial`, `transactional` |
| `target_audience` | string | No | E.g., "Small business owners," "Software engineers," "Students" |
| `tone` | string | Yes | One of: `formal`, `casual`, `persuasive`, `friendly`, `professional`, `educational`, `authoritative` |
| `text` | string | Yes | The text to be humanized (min 10 chars) |

#### Response

```json
{
  "humanized_content": "The rewritten text goes here.",
  "word_count_actual": 42,
  "success": true
}
```

#### Example

```bash
curl -X POST "https://raza-content-project-e3btaubfb2hdfpd7.southeastasia-01.azurewebsites.net/api/v1/humanize" \
  -H "Content-Type: application/json" \
  -d '{
    "content_type": "informational",
    "target_audience": "Students",
    "tone": "friendly",
    "text": "Machine learning is a subset of artificial intelligence that enables systems to learn and improve from experience without explicit programming."
  }'
```

## Performance & Scalability

- **Startup time:** ~2 seconds (cold start on Azure)
- **Request latency:** 2-4 seconds per humanize request (depends on text length & Azure response time)
- **Concurrent users:** App Service auto-scales with Gunicorn workers
- **Throughput:** ~15-20 requests/second on B1 tier

For production, upgrade to B2 or higher Azure tier for better performance.

---

## Known Limitations

- **Requires Azure OpenAI credentials** for real AI features (falls back to mock AI for testing)
- **No user authentication** — The app is public and stateless
- **Text length limit** — ~10,000 characters per request (Azure token limit)
- **No rate limiting** — Consider adding if serving many users
- **No caching** — Each request hits the AI API (adds latency & cost)

## Troubleshooting

### App won't start locally
```bash
# Make sure virtual environment is activated
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate     # Windows

# Reinstall dependencies
pip install -r requirements.txt

# Check Python version (must be 3.11+)
python --version
```

### `ModuleNotFoundError: No module named 'fastapi'`
```bash
pip install -r requirements.txt
```

### API returns "Azure credentials not configured"
- Add Azure keys to `.env` file
- Or use mock AI for testing (app works without real keys)

### Deployment fails on Azure
- Check **Log stream** in Azure Portal
- Ensure `SCM_DO_BUILD_DURING_DEPLOYMENT=true` in App Settings
- Verify publish profile secret is up-to-date in GitHub
